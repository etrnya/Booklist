    🤖 AI 視覺模型辨識 (拍照無條碼時使用)
    💡 Google Gemini API Key 免費申請 5 步驟：
    1. 點擊前往 Google AI Studio 官方金鑰頁面 ↗
    2. 登入個人 Google 帳號（個人 Gmail 即可，完全免費免綁信用卡）。
    3. 點擊藍色按鈕 「Create API key」。
    4. 在跳出的選單點選「Create key in new project」建立新專案金鑰。
    5. 點擊複製產生的金鑰（以 AIzaSy... 開頭），回此頁貼上即可！
    註：金鑰 100% 僅儲存於您本地手機/電腦瀏覽器，絕不經過任何第三方伺服器。
    📓 Notion 書櫃同步 (選填·連結個人書櫃)
    💡 Notion 書櫃 3 步驟串接指引：
    1. 步驟 1：建立 Notion Integration (取得 API Token)
      前往 Notion 官方開發者整合頁面 ↗，點選「+ New integration」，輸入名稱（例如 Booklist），選取您的 Workspace，權限保持「Read content」與「Insert content」，建立後複製 Internal Integration Secret（格式如 secret_... 或 ntn_...），貼至下方 Token 欄位。
    2. 步驟 2：取得「我的書櫃」Database ID
      在瀏覽器打開您的 Notion「我的書櫃」資料庫頁面，查看網址列：
      https://www.notion.so/workspace/45ff2f178ffe4bf58d417fc0dfece19f?v=...
      複製斜線後、問號前的 32 位英數字元代碼，貼至下方 Database ID 欄位。
    3. 步驟 3：最關鍵！在 Notion 頁面授權連線
      打開該 Notion 書櫃頁面 ➔ 點擊右上角「···」（選單） ➔ 點選「Connections」（或「Connect to / 新增連線」） ➔ 搜尋並選取您剛剛建立的 Booklist Integration 進行授權！
      ⚠️ 若未在此步驟授權連線，Notion API 將會阻擋存取並回傳 404！
    完成以上設定後點擊下方「💾 儲存設定」，系統即可直接與您的 Notion 雲端書櫃雙向連線！
